# leftfootLabs

Coming-soon landing page for **leftfootLabs** — small, 3D-printed 5U 10-inch homelab rack kits for homelabbers without a printer of their own. Modeled in Blender, printed in PETG.

**Live:** [leftfootlabs.com](https://leftfootlabs.com)

## What this is

A single static page (`index.html`, no build step) holding the spot while the storefront itself is on hold until [the capstone project](https://github.com/MichaelRooney99/homelab-status) clears its required hours. Points visitors at the [Rack Planner](https://planner.leftfootlabs.com) in the meantime.

## Related

- [Rack Planner](https://planner.leftfootlabs.com) — companion app for planning rack builds, scaffolded and in progress
- [michaelrooney.dev](https://michaelrooney.dev) — portfolio and build journal
